Automatisch übersetzen mit DeepL

Lass Inhalte über die DeepL-Integration automatisch übersetzen oder übersetze sie selbst. Der Premium-Plan bietet bis zu 1.000.000 automatisch übersetzte Zeichen pro Monat, Übersetzungs-Jobs im Hintergrund und ein Glossar.

Laut DeepLs Blindtests aus dem Jahr 2020 entschieden sich professionelle Übersetzer viermal so häufig für die Ergebnisse von DeepL wie für die Ergebnisse jedes einzelnen Vergleichssystems. DeepLs Testergebnisse lesen (Englisch).

Native Integration und Speicherung

Easy Translation basiert auf Shopifys Translation API und verbindet deinen Shop mit Shopifys Übersetzungen. Deine bearbeiteten Übersetzungen werden dauerhaft im Shopify-Ökosystem gespeichert, niemals auf unseren Servern.

Die App ist einfach, schlank und fügt sich in die Architektur deines Shops ein. Sie nutzt dieselben Werkzeuge wie der Shopify-Adminbereich und fühlt sich dadurch vertraut an. Du musst keine Theme-Dateien ändern.

Datenschutz von Anfang an

Wir fordern nur die Daten an und greifen nur auf die Daten zu, die für die Funktion der App benötigt werden. Gespeicherte Daten beschränken wir auf das absolute Minimum. Sensible Daten werden weder abgerufen noch gespeichert.

Einzelheiten zu Datenzugriff, Speicherung und Verarbeitung findest du in unserer Datenschutzerklärung (Englisch).
