Automatic translation with DeepL

Choose automatic translation through the DeepL integration or translate resources manually. The Premium plan includes up to 1,000,000 automatically translated characters per month, background translation jobs, and a glossary.

In its 2020 blind tests, DeepL reported that professional translators chose its output four times as often as each competing system’s output. Read DeepL’s test results.

Native integration and translation storage

Easy Translation is built on Shopify’s Translation API and connects your store to Shopify’s translations. Your curated translations are permanently stored in Shopify’s ecosystem, never on our servers.

The app is simple, lightweight, and fits into your store’s architecture. It uses the same toolbox as Shopify’s admin, so it feels familiar, without requiring changes to any theme files.

Built with privacy in mind

We only request and access the data needed to make the app work. The data we store is kept to an absolute minimum. No sensitive data is accessed or stored.
